## О курсе

Платформа предназначена для публикации материалов бакалаврского курса «Основы построения инфокоммуникационных сетей и систем» в виде веб-сайта. Материалы дополняются по мере разработки.

Лекции, практика и справочные страницы содержат интерактивные демонстрации: параметры сигналов и каналов можно менять прямо в браузере и наблюдать результат.

## Содержание

- Лекции, практический материал и справочные страницы в формате QMD; раздел лабораторных работ пока содержит страницу-заготовку.
- JavaScript-модели и интерфейсы интерактивных демонстраций.
- Python-модель аудиоканала, скрипты генерации иллюстраций и данных, тесты моделей и ресурсов.
- Изображения, аудиоданные, стили и конфигурация сборки и публикации.

## Технологии

Quarto / QMD → HTML · JavaScript (ES-модули) · SCSS / CSS · Python · GitHub Actions · GitHub Pages.

## Разработка и адаптация

Репозиторий можно форкнуть и адаптировать как основу собственной учебной платформы: заменить QMD-материалы, настроить навигацию и адрес сайта в `course/_quarto.yml`, переиспользовать нужные интерактивные компоненты.

Для локального просмотра установите Quarto **1.10.18**, затем из корня репозитория выполните:

```bash
cd course
quarto preview
```

## Сборка и публикация

Workflow [Check site](https://github.com/temaSW/intro-to-networking/actions/workflows/check.yml) запускается при push, pull request и вручную. GitHub Actions устанавливает Python 3.11, Quarto 1.10.18, `pytest` и `numpy`, запускает тесты и выполняет `python scripts/check.py` для сборки всего сайта.

После успешной проверки ветки `main` при push или ручном запуске workflow загружает `course/_site/` как артефакт Pages и публикует его через `actions/deploy-pages`. Pull request и другие ветки проходят проверку без публикации. Для форка настройте GitHub Pages на публикацию через GitHub Actions и укажите собственный `site-url`.
