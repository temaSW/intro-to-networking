Получить ответ через GitHub Actions

Если сайт не разрешает браузеру читать ответ, запрос можно выполнить на машине GitHub. Для запуска нужен вход в GitHub и право запускать задания этого репозитория.

Открыть эксперимент в GitHub: Run workflow → поле url → Run workflow. После завершения задания в разделе Artifacts доступен архив http-response. Из него нужен файл response.json.

Адрес и результат задания доступны в GitHub. В этом режиме запрос выполняет машина GitHub, а страница читает сохранённый ответ.
