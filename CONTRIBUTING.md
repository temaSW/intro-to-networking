# Как помочь проекту

## Ошибки и предложения

Для опечаток, ошибок в формулах, неработающих ссылок и демонстраций используйте форму Issue «Ошибка». Укажите страницу, проблемный фрагмент и ожидаемый результат. Для новых материалов используйте форму «Предложение». Проверьте существующие Issues перед созданием нового. Не прикладывайте персональные данные студентов и закрытые материалы.

## Pull request

1. Создайте форк и отдельную ветку.
2. Меняйте исходники в `course/`; сгенерированный `course/_site/` не добавляйте в Git.
3. Соблюдайте [формат лекций](docs/lecture-format.md) и [правила оформления](docs/site-style.md).
4. Проверьте затронутые страницы в браузере, включая мобильную ширину. Для интерактивов проверьте крайние значения и сброс.
5. Опишите изменение и выполненные проверки в pull request.

## Локальный запуск

Требуются Python 3.11+, Quarto 1.10.18 и Node.js для JavaScript-тестов.

```bash
cd course
quarto preview
```

Проверки из корня репозитория:

```bash
python -m pip install pytest numpy
python -m pytest -q
python scripts/check.py
```

Для текста проверьте сборку и отображение страницы. Для моделей запускайте тесты и при необходимости добавляйте проверку исправленного поведения. CI выполняет тесты и сборку для каждого PR. Подробнее: [сборка и публикация](docs/deploy.md).

Предлагая изменения, укажите, если для вашего вклада нужны другие условия. Не включайте чужие материалы без совместимого разрешения; сохраняйте источники, сведения об авторстве и отдельные уведомления о лицензиях.
