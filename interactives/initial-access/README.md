# От принятого сигнала до первого блока

`course/reference/initial-access.qmd` содержит одну историю телефона A и пять микроэкспериментов: поиск кадра, остаточная ошибка несущей, системная информация, конкуренция обращений, адресный обмен до данных. Это справочная страница, без формата лекции.

## Модули

- `initial-access-model.js`: модель знаний и разрешений `InitialAccess`, независимая модель конкуренции `Contention`, численные наблюдения `frameObservation` и `carrierObservation`.
- `initial-access-ui.js`: `mountInitialAccess(root)`, контейнер `[data-initial-access-story]` с `[data-progress]` и пятью `[data-experiment]`: frame, carrier, system, access, exchange. Контроллер предоставляет `simulation`, `contention`, `reset()`.
- `initial-access.css`: переменные темы курса, адаптивные схемы, клавиатурный фокус, reduced-motion.

Корреляция переиспользует `correlationIllustration` из `transmission-agreement-model.js` (чистая функция без UI). Для несущей используется тот же фазовый поворот exp(j2πΔft), но отдельный тонкий расчёт позволяет студенту вручную задать оценку, вместо готовой автоматической компенсации существующего frequency demo. Лекция и её незавершённые изменения не затрагиваются.

В начале известен только символьный такт; один блок уже ожидает отправки. Правила нельзя прочитать до кадра и уточнения несущей. При успехе общего доступа создаётся только временный контекст и служебное назначение. Индивидуализация позволяет адресный запрос; пользовательское назначение содержит точные ресурс и время. Передача расходует его.

Конкуренция сначала ручная (два телефона / четыре варианта), затем случайная. `attempt()` даёт наблюдение сети; телефоны продолжают ждать. `response()` либо выдаёт контекст, либо завершает ожидание тайм-аутом и назначает повторное окно. Случайность фиксирована seed и воспроизводится после reset. Успешные участники исключаются из следующих попыток. После получения A контекста остальные участники могут завершить свой доступ, а A — адресный обмен. Изменение условий конкуренции начинает эту часть истории заново, сохраняя PHY и общие правила.

В численных опытах нет шума, PLL и полноценного PHY acquisition. Корреляционная опора известна; период кадра 48 символов. Частотная ошибка 25 Гц, шаг наблюдений 4 мс, компенсация считается достаточной при остатке ≤1 Гц. В конкуренции нет capture effect/ошибок PHY. Учебные окна служебного обмена не имеют масштаба миллисекунд и не соответствуют слотам стандарта.

## Сохранённая модель нагрузки

Прежний `InitialAccess` с FIFO, непрерывными приходами и scheduler сохранён без изменений в `course/interactives/resource-load-model.js`. Его прежние тесты находятся в `tests/test_resource_load.py`. Он не импортируется этой страницей. Это самостоятельная модель для будущей темы распределения ресурса; прежний универсальный UI удалён.
