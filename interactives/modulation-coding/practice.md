# Проверка расчётов и выбор MCS

Страница `course/practice/choose-mcs.qmd` подключает независимые компоненты
`course/interactives/mcs-practice-ui.js` через `data-mcs`: `rates`, `ber`,
`thresholds`, `selector`, `file`, `shannon`. Каждый блок можно использовать
самостоятельно; данные загружаются один раз для всех блоков страницы.

Предметная модель `mcs-model.js` отделена от DOM. Скорости выражены в Мбит/с
при символьной скорости в Мсимв/с, объём — в Мбит, время — в секундах.
Расчёт Шеннона принимает МГц и SNR в дБ (отношение мощностей в полосе).
BER использует Es/N₀ в нормировке существующей модели.

Единственный источник порогов — `course/data/lecture-04/nr-ber-awgn.csv`.
Порог — первый измеренный отсчёт с BER ≤ 10⁻³. Селектор предполагает
монотонное улучшение качества за порогом и не интерполирует BER. При отсутствии
допустимого режима возвращается `null`. Нулевые ошибки остаются в таблице;
логарифмический график их не показывает. График переиспользует `berSvg` из
`lecture-04-ui.js`; опциональная линия требования не меняет лекционный вывод.

Проверки не открывают численные ответы до заполнения всех полей блока;
селектор требует собственного выбора. Изменение данных скрывает старый ответ.
Числовой допуск 0,011 допускает округление до сотых; номера и пороги проверяются
точно. Ошибки сопровождаются объяснением операции. Используются общие цвета,
рамка `.course-demo`, локальная клавиатурная прокрутка и `aria-live`.

Проверки: `node --test tests/test_mcs.mjs`, `python scripts/check.py`.
