# Где узкое место?

Самостоятельный компонент вводной лекции. Предметная модель — `course/interactives/bottleneck-model.js`, интерфейс — `course/interactives/bottleneck-ui.js`. Используется в `course/lectures/00-introduction.qmd` и отдельно в `course/lectures/00-bottleneck.qmd`.

Параметры: активные пользователи `N`, запрос на пользователя `r` и ёмкости трёх общих сегментов, все скорости в Мбит/с. Модель считает `L = N × r`, предлагаемую загрузку `L / Cᵢ`, доступную суммарную скорость `min(L, min Cᵢ)` и оценку на пользователя `min(r, min Cᵢ / N)`. Узкими названы сегменты с минимальной ёмкостью; если нагрузка ниже неё, фактической перегрузки нет. Значения служат для учебной оценки, а не для прогноза работы 5G или TCP.
