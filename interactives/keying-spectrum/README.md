# Спектры ASK, FSK и PSK

Компонент `course/interactives/lecture-04-spectrum-model.js` вычисляет нормированные спектральные огибающие; `lecture-04-spectrum-ui.js` отображает их и управляет опытом. Он используется в лекции 04 и на странице моделей.

Параметр для студента — длительность бита $T_b$. Горизонтальная ось показывает отклонение частоты от несущей; диапазон частот и шкала уровня фиксированы при переключении режимов. Штриховая кривая при $T_b=1$ мс служит ориентиром.

Модель использует огибающую $\mathrm{sinc}^2$ прямоугольного битового импульса. Для ASK и BPSK непрерывные части имеют одинаковую форму; у ASK отдельно показана дискретная линия несущей. Для FSK показана сумма двух огибающих с фиксированными смещениями частот $\pm1$ кГц. Фазы между FSK-символами, формирование импульсов и фильтрация не моделируются. Нормировка каждой кривой к собственному максимуму позволяет сравнивать ширину, но не абсолютную мощность между режимами.
