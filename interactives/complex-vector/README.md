# Комплексный вектор

Независимый компонент для восстановления геометрического смысла комплексного числа: изменение модуля растягивает вектор, изменение аргумента поворачивает его.

- Модель: `course/interactives/complex-vector-model.js`, чистая функция `complexVector(modulus, angleDegrees)`; угол нулевого вектора не определён.
- Интерфейс: `course/interactives/complex-vector-ui.js`, монтируется во все элементы `[data-complex-vector]`.
- Оформление: `course/styles/complex-numbers.css`, использует переменные темы курса и масштабируемый SVG без минимальной ширины.
- Подключение: контейнер `<div data-complex-vector>` с текстом для чтения без JavaScript, CSS и модульный скрипт. Зависимостей нет.

Исходный вектор равен 1. Управление модулем (0–2) и углом (−180…180°) множителя показывает результат умножения, его проекции и численные координаты. Сначала предложить предсказать действие множителя j, затем проверить поворот на 90° при сохранении длины.
