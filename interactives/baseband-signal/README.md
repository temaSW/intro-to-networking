# Формирование сигнала основной полосы

Публичная тема: `course/lectures/01-baseband-signal.qmd`. Она объединяет независимые компоненты дискретизации, квантования и линейного кодирования. Управления одного опыта не изменяют параметры другого.

## Дискретизация

Переиспользованы `sampling-model.js`, `sampling-ui.js`, `sampling-vivid.css` из справочника о теореме Котельникова. Временная модель — синусоида с фиксированной фазой, частота в кГц, время в мс. Низкочастотная копия совпадает с исходной в точках отсчётов; это иллюстрация неоднозначности, а не универсальный алгоритм восстановления. Демонстрация копий спектра остаётся в справочнике и не включается в тему 01: она не повторяет изучение преобразования Фурье.

## Квантование

`quantization-model.js` — чистая предметная модель; `quantization-ui.js` и `quantization.css` — независимые экземпляры интерфейса.

Диапазон квантователя: [-1, 1] в относительных единицах. При n битах используется 2^n интервалов, а уровень восстановления — середина интервала. У крайних входов номер ограничен крайним кодом. Входы за пределами диапазона отмечены как перегрузка; ошибка вычисляется относительно исходного входа до ограничения.

Нелинейная шкала: c(x) = sign(x) ln(1 + 255 |x|) / ln(256). В координате c выполняется равномерное квантование; центр интервала проходит через точное обратное преобразование. Это непрерывная учебная μ-характеристика, не битовая реализация G.711. Отдельный существующий компонент А-характеристики оставлен как пример стандарта в закрытом пояснении.

Временной опыт: синтетический сигнал, частота дискретизации 8 кГц, окно 4 мс (33 отсчёта с обеими границами). Шкалы графика фиксированы; исходная амплитуда изменяется от 0,1 до 1,4. Квантованные отсчёты соединены ломаными для визуального сравнения, без вычисления дополнительных отсчётов или модели восстановления. Равномерная шкала показана сплошной синей линией, нелинейная — пунктирной фиолетовой; те же линии используются в легенде. Вертикальные отрезки в отдельном опыте равномерного квантования показывают ошибку; квадраты отмечают перегруженные исходные отсчёты. Максимальная ошибка относится к показанным 33 точкам, не ко всем возможным входам. Номер отсчёта в скрытом блоке позволяет проверить кодовое слово и численную ошибку.

## Проверки

`tests/test_quantization.py`: границы ошибки равномерного квантования без перегрузки, принадлежность входов интервалам, монотонность нелинейной шкалы, кодовые слова, перегрузка, выигрыш/проигрыш компандирования при малой/большой амплитуде сложного сигнала, совпадение алиасной синусоиды в отсчётах. Существующая проверка `test_companding_line.py` сохраняет покрытие А-характеристики и линейных кодов.

На телефоне график квантования и числовая таблица прокручиваются внутри доступного с клавиатуры контейнера. Светлая и тёмная темы получают цвета из общей палитры.

Первое объяснение равномерного квантования использует `data-quantization-point`: один отсчёт от −1,4 до +1,4, 2–4 бита, интервалы, номер, середина интервала, кодовое слово и знаковая ошибка. Начальный пример: 0,37 → интервал №5 [0,25; 0,50) → 0,375 → 101; ошибка 0,005. Последний интервал включает правую границу шкалы. При перегрузке выбирается крайний интервал, но вход находится вне него; интерфейс явно сообщает перегрузку. Временная демонстрация равномерного квантования закрыта по умолчанию.

Сложный сигнал формируется из трёх гармонических составляющих 1,1; 2,35; 3,1 кГц с весами 0,55; 0,3; 0,15 и разных фаз. Огибающая — фон 0,07 и четыре гауссовых всплеска (центр, ширина, вес): (0,65; 0,22; 0,27), (1,65; 0,33; 0,55), (2,7; 0,27; 0,85), (3,5; 0,2; 0,4), время в мс. Значения на сетке 8 кГц нормированы по максимальному модулю и соединены линейной интерполяцией. Параметр амплитуды задаёт точный максимальный модуль исходной кривой. Это синтетический учебный сигнал с кусочно-линейной формой, не запись речи; частотная полоса для него не заявляется. Выбор формы отсутствует: оба опыта используют один сложный сигнал.
