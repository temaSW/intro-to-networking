# От импульса к несущей

Самостоятельный интерактив для `course/practice/impulse-to-carrier.qmd`.
`course/interactives/impulse-ask-model.js` содержит вычислительную модель;
`impulse-ask-ui.js` создаёт интерфейс внутри элемента `data-impulse-ask`.
Обе части являются обычными ES-модулями и выполняются в браузере без backend.

Дискретизация 1 МГц, FFT на 4096 отсчётов. В интерфейсе `fc ≤ 180 кГц`,
`Rb ≤ 25 кбит/с`, поэтому даже четыре первых боковых лепестка находятся
ниже частоты Найквиста. Первый этап использует аналитический sinc; для
конечных наборов битов показана FFT именно отображаемого фрагмента.
Фильтр идеальный прямоугольный и реализован как FFT → маска → IFFT.
Резкие края фильтра могут вызывать звон. Графики положительных частот
нормированы каждый к своему максимуму; оценка главной области по первому
нулю служит ориентиром, а не строгой границей спектра.

Запуск: `python scripts/check.py`, затем открыть
`course/_site/practice/impulse-to-carrier.html` через локальный HTTP-сервер
(`python -m http.server 8000 --directory course/_site`).
