# Практика по спектрам

Самостоятельные интерактивы для `course/practice/impulse-to-carrier.qmd`.
`course/interactives/impulse-ask-model.js` содержит вычислительные модели,
`impulse-ask-ui.js` создаёт интерфейс внутри элементов `data-impulse-ask`.
Обе части — обычные ES-модули без серверной части.

Ряд Фурье вычисляется по аналитическим коэффициентам. Спектры ASK, FSK и BPSK
получаются усреднением мощности оконной FFT. В эксперименте переноса три
синусоиды с частотами 5, 12 и 20 кГц умножаются на косинус несущей. Их
положительные частоты становятся парами `fc − f` и `fc + f`, а амплитуды
уменьшаются вдвое. Идеальный фильтр низких частот пропускает линии с
частотой не выше установленной границы; отсечённые линии показаны пунктиром.
На графиках после переноса на несущую фильтр показан границей и отсечёнными
пунктирными линиями; отдельного этапа фильтра нет. Затем сигнал умножается
на ту же несущую с коэффициентом 2, а приёмный ФНЧ 25 кГц оставляет
составляющие около нуля. На последнем временном графике исходный сигнал показан
пунктиром для сравнения. Для каждого этапа рядом со спектром синтезируется
форма сигнала за 0,2 мс.

Проверка: `python scripts/check.py`. Страница после сборки:
`course/_site/practice/impulse-to-carrier.html`.
