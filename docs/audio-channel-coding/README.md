## Модуляция и SNR

Во всех режимах `SNR_dB=10*log10(Ps/Pn)`, `Ps=mean(s_RF²)`,
`Pn=var(n_RF)=Ps/10^(SNR/10)`. SNR измеряется в канале до демодуляции,
включая мощность несущей. При 0 dB мощности равны.

**Analog · AM:** `s=(1+x)*cos(2*pi*fc*t)`, индекс модуляции 1, пик сообщения
0.85, без перемодуляции. Для аудио 8 kHz: расчётная частота 32 kHz,
несущая 8 kHz. Интерполяция через FFT периодическая, как аудиопетля.
После RF AWGN: умножение на удвоенную несущую, идеальный FFT НЧ-фильтр
до 4 kHz, прореживание до 8 kHz, вычитание DC=1. Без шума восстанавливается
исходное аудио. `Ps≈mean((1+x)²)/2`; постоянная несущая учитывается в SNR.
Выходная дисперсия шума примерно `Pn/2` для этой дискретизации.

**Digital · OOK:** PCM8 MSB first, 0 выключает несущую, 1 включает.
Один период и четыре отсчёта `[1,0,-1,0]` на бит; 64 kbaud, несущая
64 kHz, расчётная частота 256 kHz. Коррелятор `y=sum(r*c)/sum(c²)`;
порог 0.5. `sum(c²)=2`, поэтому дисперсия шума коррелятора `v=Pn/2`.
Мощность `Ps=mean(bits)/2` вычисляется по фактической последовательности,
включая padding и проверочные биты. При равновероятных битах и 0 dB
BER=`0.5*erfc(1)=0.0786496`; точная модель учитывает измеренную долю единиц.

Цифровой генератор рисует непосредственно нормальный шум достаточной
статистики коррелятора с дисперсией `Pn/2`. Это точное распределение
результата четырёхотсчётного RF-канала с независимым AWGN. Тест сопоставляет
его с явной модуляцией, RF-шумом и корреляцией. Шум после PCM не добавляется.

**Digital + LDPC · OOK:** тот же модулятор. Logits для Sionna:
`log(P(1)/P(0))=(y-0.5)/v`, равноприоритетные битовые гипотезы.
Синхронизация фазы и времени идеальна; CRC, ARQ, HARQ, concealment и
отбрасывание кадров отсутствуют.

Полоса, время и информационная скорость между режимами не уравниваются.
При той же скорости символов LDPC занимает втрое больше времени.
Браузер воспроизводит восстановленное аудио в исходном темпе.
Для заменяемого WAV частоты масштабируются с его частотой дискретизации.

Документация AM: [MathWorks](https://www.mathworks.com/help/comm/ug/amplitude-modulation.html).

## Код и измерения

Sionna 2.2.0 (`sionna-no-rt`, PyTorch): `LDPC5GEncoder(k=2048,n=6144)` и
`LDPC5GDecoder(cn_update="boxplus-phi",num_iter=30)`, flooding BP,
стандартный предел LLR 20. Base graph, lifting, rate matching выбирает Sionna.
R=1/3, 262144 информационных бита, 128 блоков без padding,
786432 OOK-символа. Manifest отдельно учитывает padding заменяемого WAV.

[Encoder](https://nvlabs.github.io/sionna/phy/api/fec/ldpc/sionna.phy.fec.ldpc.LDPC5GEncoder.html),
[decoder и знак logits](https://nvlabs.github.io/sionna/phy/api/fec/ldpc/sionna.phy.fec.ldpc.LDPC5GDecoder.html).

Кандидаты `(k,n,BP)`: `(1024,3072,20)`, `(2048,6144,30)`, `(2048,8192,40)`.
По 128 случайных блоков на точку, PCG64: payload seed 20261102,
noise seed 20261202. Общий стандартный шум масштабируется по SNR;
соседние точки не являются независимыми испытаниями.
Все кривые пересчитаны для OOK: [benchmark.csv](benchmark.csv),
[benchmark.svg](benchmark.svg). Нули на логарифмической оси показаны ниже `1/N`.

Переход выбранного кода около −4.5 dB. При 0 dB на 128 блоках ошибок нет.

| SNR, dB | BER после LDPC | Ошибочные блоки |
|---:|---:|---:|
| −5 | 0.134022 | 128/128 |
| −4.75 | 0.0573997 | 97/128 |
| −4.5 | 0.00878906 | 27/128 |
| −4.25 | 0.000179291 | 1/128 |
| −4 | 0 | 0/128 |
| 0 | 0 | 0/128 |

Длинный блок R=1/3 выбран как компромисс: короткий при −4 dB ещё имеет
10 ошибочных блоков из 128, а R=1/4 требует дополнительной избыточности.

Это конечная выборка: односторонняя 95%-граница FER для независимых 0/128
около 2.31 %. Независимость битовых ошибок BP не гарантируется.
Точные измерения звукового фрагмента сохранены в публичном manifest.

## Источник, воспроизведение и проверки

4.096 s, mono 8 kHz, восемь трёхсинусовых созвучий. Частоты 261.6256,
329.6276, 391.9954, 523.2511, 440, 391.9954, 329.6276, 293.6648 Hz;
отношения 1, 1.25, 1.5, амплитуды 1, 0.45, 0.3. Окно sin² обнуляет
границы, пик 0.85. Внешних записей нет. PCM8:
`round((clip(x,-1,1)+1)*127.5)`, unsigned, уровни −1…+1, MSB first.
Даже при нулевом BER остаётся погрешность квантования.

Шум действует до демодуляции. Редкие ошибки старших PCM-битов дают выбросы,
плотные ошибки сливаются в шум. При 9 dB в Digital редкие ошибки;
при 10 dB в данном фрагменте их нет. После синхронной AM-демодуляции
исходные тоны остаются частью восстановленного сигнала.

Сетка −6…+16 dB, шаг 1 dB, seed 20261002. Один общий gain по максимальному
пику всей сетки исключает клиппинг; нормализации по режимам нет.
Пакеты little-endian PCM16 около 4.6 MB; SHA-256, метрики, параметры в manifest.
Waveform min/max, общий масштаб, курсор по аудиочасам. AudioContext после Play,
loop сохраняет позицию, crossfade 35 ms, Pause fade 25 ms.
Светлая/тёмная тема, узкий экран, без внешних JS-библиотек.

Windows, Python 3.14.2, CPU, четыре потока PyTorch. Численные версии в manifest,
окружение `scripts/requirements-audio-lock.txt`. Sionna не нужна для сборки сайта.

```powershell
python -m venv .tools/audio-env
.tools/audio-env/Scripts/python.exe -m pip install -r scripts/requirements-audio-lock.txt
.tools/audio-env/Scripts/python.exe scripts/benchmark_audio_channel.py
.tools/audio-env/Scripts/python.exe scripts/generate_audio_channel_demo.py
.tools/audio-env/Scripts/python.exe -m pytest -q
python scripts/check.py
```

В Linux `.tools/audio-env/bin/python`. Замена источника:
`scripts/generate_audio_channel_demo.py --source path/to/mono-pcm16.wav`.
Для плавного loop подготовьте границы WAV; длина и частота читаются из файла.
Пакеты, manifest, SVG/CSV коммитятся. CI с numpy/pytest проверяет модель и assets;
три теста реального LDPC запускаются в offline-окружении.
Проверки: восстановление AM без шума, выходная дисперсия, OOK-коррелятор против
явного RF-расчёта, теоретическая BER/ошибка PCM, неповреждённые отсчёты,
независимое побайтовое восстановление цифрового пакета, LDPC и повторяемость.
