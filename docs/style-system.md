# Устройство Style Lab

Три страницы в `course/style-lab/` подключают один `_content.qmd` через штатный Quarto include. Общая разметка описывает смысл блоков (`engineering-problem`, `predict`, `figure-explanation`, `model`, `experiment`, `takeaway`), поэтому страницы могут менять композицию без копирования текста.

`course/styles/base.scss` задаёт семантические цвета для светлой и тёмной темы, доступные состояния ссылок, таблиц и общей схемы. Каждый файл в `course/styles/variants/` меняет ширину, типографику, ритм и компоновку. Варианты подключаются на уровне front matter страницы как дополнительные элементы соответствующих Quarto light/dark themes.

При изменении общего текста проверяйте все три страницы на широком и узком экране, в обеих темах. Новые смысловые блоки сначала добавляйте в общий фрагмент, затем оформляйте во всех вариантах.

## Изображения и схемы

Все содержательные изображения на публичных страницах должны открываться по клику в увеличенном виде. Это касается обычных `<img>`, встроенных SVG и схем Mermaid. Подключайте `course/interactives/image-lightbox.js` на страницах с иллюстрациями; он также обрабатывает графики, добавленные интерактивом после загрузки страницы. Для SVG задавайте `role="img"` и понятный `aria-label`. Изображение должно открываться клавишами Enter и пробел, закрываться Escape или кнопкой, а после закрытия фокус должен возвращаться к нему. Только для элементов, где увеличение мешает основному действию, используйте класс `no-lightbox`.
