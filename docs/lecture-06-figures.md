# Векторная схема ИКМ-30

Исторический материал: после переработки лекции 06 вокруг общих инженерных задач эта схема не используется на её странице. Файл сохранён вместе с происхождением для возможного отдельного разбора технологии.

`course/assets/lecture-06/pcm-30-structure.svg` извлечена из векторного оригинала: А. В. Пуговкин. «Основы построения инфокоммуникационных систем и сетей». ТУСУР, 2022. С. 65, рис. 4.46. Источник: https://edu.tusur.ru/publications/9600 ; локальная копия: `../архивное/current/Учебное пособие.pdf`.

SVG содержит векторные линии и контуры шрифтов, без `<image>` и встроенных растров. Обрезаны поля страницы и номер; добавлен белый фон. В адаптации исправлены значение и подпись Р2 КИ 0 нечётных циклов: фиксированная 1 по G.704, таблица 5A. Другие назначения отражают исторический вариант ИКМ-30 из пособия; нижние схемы в прежней версии лекции описывали общий формат G.704.

При прежнем использовании атрибуция и ссылка на пособие находились в подписи рисунка. Конвертер установлен только в игнорируемой `.tools/pcm-review/vendor`; зависимости сайта не менялись. Ранее использовавшийся растровый образец заменён.
