# Проверка рекомендуемой литературы и ссылок

Дата проверки: 9 октября 2026 года. Документ предназначен для сопровождения исходников, не для публикации на сайте.

Основным учебным ресурсом является сайт курса. Три внешних учебника рекомендованы автором для углубления и альтернативных объяснений; они не определяют структуру и обязательное содержание дисциплины.

## Внешние ссылки: проверка не завершена

Найдена [актуальная официальная страница перечня Минюста РФ](https://minjust.gov.ru/ru/pages/perechen-inostrannyh-i-mezhdunarodnyh-organizacij-deyatelnost-kotoryh-priznana-nezhelatelnoj-na-territorii-rossijskoj-federacii/). Доступное представление содержит только кнопку «Загрузить реестр», без записей перечня; переход по кнопке возвращает ту же страницу. Прямой запрос из локальной среды возвращает HTTP 403. Старый адрес `/ru/documents/7756/` возвращает HTTP 404.

Полный актуальный перечень не получен, поэтому сопоставление юридических лиц с ним не выполнено. Отсутствие результатов поискового запроса не использовалось как подтверждение. Юридический статус организаций не установлен; вывод о допустимости ссылок не сделан.

По прямому уточнению автора ссылки на российские издательства допускаются. На главной сохранены ссылки на книги у «Питер» и «Вильямс» и на запись Прокиса в РГБ. Российское место издания подтверждено библиографическими источниками; [сайт «Питер»](https://www.piter.com/page/o-kompanii) также описывает издательство в России и указывает адрес в Санкт-Петербурге. Эта редакционная договорённость не означает проверки юридического статуса по полному перечню Минюста.

Для иностранных ресурсов ITU и MIT применён предусмотренный задачей вариант: названия и описания сохранены без исходящих ссылок до ручной проверки. Внутренняя ссылка на справочник курса работает. Ссылки в этом документе сохраняют свидетельства проверки для автора; документ находится вне публичного `course/`.

Для ручной проверки перед возвращением исходящих ссылок:

1. Получить полный актуальный официальный перечень Минюста и зафиксировать дату его версии.
2. Установить юридических операторов иностранных ресурсов, учитывая различие торговых марок, импринтов и юридических лиц; сопоставить их с перечнем. Для российских издательств действует отдельное разрешение автора.
3. Проверить операторов существующих ресурсов [ITU-T G.711](https://www.itu.int/rec/T-REC-G.711) и [MIT 6.02, лабораторная 7](https://web.mit.edu/6.02/www/s2010/handouts/labs/lab7.shtml). Содержание этих страниц доступно и соответствует описаниям, но проверка по полному перечню не завершена.
4. Возвращать проверенные уместные ссылки на иностранные ресурсы. Не добавлять неавторизованные загрузки книг.
