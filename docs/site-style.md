# Оформление и пошаговые сцены курса

Сайт собирается из `course/` командой `python scripts/check.py`. Общие цвета, шрифт, ширины и интервалы находятся в `course/styles/base.scss`. Для обычной страницы используйте основную колонку: текст в ней ограничен по длине строки, а рисунок может занять всю ширину колонки.

## Ширина материала

- Обычный текст и небольшие рисунки: стандартная колонка Quarto.
- Крупная схема: оберните рисунок в `::: {.column-page .course-visual}`.
- Широкая модель: оберните интерактив в `::: {.column-page .course-interactive}`.
- `column-screen`: только для фрагмента, которому нужна ширина экрана, например сцены Closeread.

Широкие контейнеры используют сетку Quarto и имеют внутренние отступы на узком экране. Не задавайте ширину рисунка через inline-стили, если достаточно этих классов.

## Смысловые блоки

В лекциях инженерский вопрос оформляется цитатой Markdown (`>`); готовый вывод не помещают в тот же блок. Для справочных страниц используйте `::: {.course-block .course-question}` для постановки задачи, `.course-observation` для наблюдения, `.course-important` для важного ограничения и `.course-extra` для дополнительного материала. Спокойный нейтральный блок без акцента — `::: {.course-block}`. Существующие классы `.engineering-problem`, `.takeaway`, `.predict` и `.real-example` используют ту же систему оформления.

## Closeread

Closeread 1.0.1 хранится локально в `course/_extensions/closeread/`. Он нужен для управляемого автором объяснения на закреплённой схеме. Модель marimo/Pyodide решает другую задачу: студент сам меняет параметры и исследует результат.

Примеры встроенных сцен: `course/lectures/00-introduction.qmd` (путь данных после гипотез аудитории), `course/lectures/03-companding-line-codes.qmd` (преобразование сигнала перед разбором квантования) и `course/lectures/04-physical-resource.qmd` (сравнение способов манипуляции перед моделью спектра). Для лекции с обычной вёрсткой подключите `closeread.lua` и `closeread.css` в локальном `format.html`; `closeread-html` меняет макет всей страницы и для встраивания не нужен. Внутри `.cr-section` поместите закреплённый блок с идентификатором `cr-*` и триггеры `focus-on="cr-*"`. Для смены состояния схемы используйте небольшой адаптер по образцу `course/interactives/closeread-scenes.js`. Каждый шаг показывает одно визуальное изменение и один короткий вопрос для диалога. Сцена должна следовать за постановкой вопроса, а не раскрывать ответ до обсуждения. Если студенту нужно самому менять параметры модели, оставьте интерактив с управлением. Проверяйте светлую и тёмную темы, телефон, контраст осей интерактивных графиков и возврат к общему виду на последнем шаге.

Синтаксис и возможности: [Closeread Guide](https://closeread.dev/guide/) и [Reference](https://closeread.dev/reference/).
