# Обратная связь через Google Forms

Три кнопки в шапке каждой страницы открывают существующие Google Forms в новой вкладке. Без JavaScript работает обычная ссылка; с JavaScript поле страницы получает полный текущий `window.location.href`, включая query и якорь. Ссылка формируется через `URL` и `searchParams`: `usp=pp_url` и соответствующее `entry.*`. Она обновляется при изменении якоря, переходе по истории, возвращении на страницу и перед открытием мышью, клавиатурой или через контекстное меню.

| Кнопка | Форма | Поле URL |
| --- | --- | --- |
| Красная — «Сообщить об ошибке» | [Ошибка](https://docs.google.com/forms/d/e/1FAIpQLScbsWOaqw31Cs30H-o3cjq4DoBKEsViXSzSD4I5BL1WjgEKfg/viewform) | `entry.2027801067` |
| Золотистая — «Предложить улучшение» | [Предложение](https://docs.google.com/forms/d/e/1FAIpQLSc70niaI42Az7F9qNkiEeF9JAoNoPknDjI07u4-hGrBYuqM-Q/viewform) | `entry.614899729` |
| Синяя — «Задать вопрос» | [Вопрос](https://docs.google.com/forms/d/e/1FAIpQLSeF4BRW5MGA_C1SvuoBoP2nhr4O8fRkI7xRpUPRTcFhe3KEXA/viewform) | `entry.633006356` |

## Схема работы

Страница курса → Google Forms → закрытая таблица ответов → Google Apps Script → GitHub Issues в `temaSW/intro-to-networking`. Отправку, Markdown и формулы проверил автор. Cloudflare и отдельный сервер не нужны. Изменять формы, их настройки и доступ к таблице для подключения кнопок не требуется.

[Закрытая таблица ответов и журнала](https://docs.google.com/spreadsheets/d/1p6L1Tc79C2dE4UtA-VfpGtsZAIkhvNBq34BnhQQDKs0/edit) предназначена для администратора. Не менять её права доступа, не публиковать ответы, журнал или иное содержимое таблицы. Эта документация находится вне публичного каталога `course/`.

## Секреты и обновление токена

**Никогда не публиковать секреты.** `GITHUB_TOKEN` хранится только в **Script Properties** работающего Apps Script. Не помещать значение токена в исходники, Git, документы, примеры, URL, чат, логи, скриншоты, артефакты сборки или публичный сайт. Публичные ссылки на формы и ID полей не являются секретами.

Использовать fine-grained token с доступом к одному репозиторию `temaSW/intro-to-networking` и разрешением **Issues: Read and write**. Не расширять доступ до всех репозиториев и не использовать локальный токен GitHub CLI.

Для обновления создать новый токен с тем же ограниченным доступом и подходящим сроком действия. В настройках работающего Apps Script заменить значение `GITHUB_TOKEN` в Script Properties, проверить корректность настройки без вывода значения, затем отозвать старый токен. Следить за сроком действия. Не переносить секрет в `Code.gs` и не публиковать его при сохранении исходника. При утечке немедленно отозвать токен и заменить его; удаление текста из последнего коммита само по себе не устраняет утечку.

## Журнал «Перенос»

Работающий скрипт ведёт журнал «Перенос». Статусы, сообщённые автором:

| Статус | Значение для администратора |
| --- | --- |
| `STARTED` | Попытка переноса начата. |
| `CREATED` | Создание Issue подтверждено. |
| `UNKNOWN` | Результат создания не подтверждён; Issue мог уже появиться. |
| `CONFIG_ERROR` | Ошибка конфигурации. |
| `API_ERROR` | Ошибка GitHub API. |
| `LIMIT` | Достигнут лимит попыток. |

`reconcileUnknown` только сверяет неопределённые результаты с GitHub, **не повторяет POST** создания Issue. Не запускать повторную отправку автоматически: это может создать дубликат. Лимит текущего скрипта — **20 попыток в сутки по UTC**, а не по локальному времени преподавателя.

Markdown и LaTeX отображаются в GitHub Issues. В Google Forms предпросмотра Markdown и формул нет.

## Исходник и проверка сайта

Актуальный исходник Apps Script локально не найден при подключении кнопок. `services/google-forms/Code.gs` не создан: работающий скрипт нельзя реконструировать по описанию или заменять устаревшим файлом из архива. При дальнейшем сохранении использовать только актуальную версию с поддержкой Markdown, без вызова `setRequireLogin`, предварительно проверив отсутствие секретов.

Проверки: `python -m pytest -q tests/test_feedback.py`, `python scripts/check.py`, проверка трёх ссылок на всех собранных страницах, обе темы, узкая и широкая ширина, клавиатура и видимый фокус, полный URL с query и меняющимся якорем, средняя кнопка и контекстное меню, ссылки без JavaScript. Перед коммитом и публикацией проверять изменения и собранный сайт на секреты. Тесты не должны отправлять ответы форм или создавать настоящие Issues. Публикация выполняется по [существующему процессу](deploy.md).
